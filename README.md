# 片手トリル速度チェッカー

片手で2種類のキーを交互に入力したときの速度を、10秒間で測定するReactアプリです。

PCではキーボード入力、タッチ端末では画面上の左右パッドに対応しています。測定結果は画面内の履歴に追加されます。

## 必要な環境

- Node.js（npmが使えるバージョン）
- PCの場合はキーボード
- タッチ端末の場合はタッチ操作が可能なブラウザ

## 起動方法

1. このプロジェクトのディレクトリへ移動します。

   ```powershell
   cd "C:\Users\user\片手トリル速度チェッカー"
   ```

2. 依存パッケージをインストールします。

   ```powershell
   npm install
   ```

3. 開発サーバーを起動します。

   ```powershell
   npm run dev
   ```

4. ターミナルに表示されたURLをブラウザで開きます。通常は次のURLです。

   ```text
   http://localhost:5173/
   ```

開発サーバーを停止するには、起動中のターミナルで `Ctrl+C` を押します。

## 動作確認

### PCで確認する場合

1. `http://localhost:5173/` を開きます。
2. 次の有効キーから、同じ手の2種類を選びます。
   - 左手: `A`、`S`、`D`、`F`、`Space`
   - 右手: `J`、`K`、`L`、`;`、`Space`
3. IMEをオフにします。
4. 選んだ2キーを交互に押します。
5. 最初のキー入力で測定が始まり、10秒後に自動終了します。
6. 合計打数、CPS、16分音符換算のBPM、使用したキーの組み合わせが表示され、測定履歴に追加されることを確認します。
7. `もう一度試す` を押すと、次の測定を開始できます。

片手測定のため、左手キーと右手キーを混ぜた組み合わせは使用できません。同じキーの連打は有効入力として数えられません。

### タッチ端末で確認する場合

1. タッチ操作に対応した端末またはブラウザでURLを開きます。
2. `LEFT` と `RIGHT` のパッドを交互にタップします。
3. 最初のタップで測定が始まり、10秒後に自動終了することを確認します。
4. 測定結果が履歴に追加されることを確認します。

## 表示項目

- **有効入力数**: 測定中に受け付けられた入力数
- **CPS**: 1秒あたりの打鍵数（入力数 / 経過秒数）
- **16分音符 BPM**: CPSをBPMに換算した値（CPS × 15）
- **測定履歴**: 過去の測定結果。ページを再読み込みするとリセットされます
