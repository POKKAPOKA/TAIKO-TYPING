# 太鼓タイピング

楽曲に合わせて流れてくるノーツの文字をタイピングする、ブラウザ向けのリズムゲームです。
公式譜面をプレイするだけでなく、ローカルの譜面・音源を使ったテストプレイと、創作譜面の作成にも対応しています。

## 主な機能

- 公式譜面の選択・プレイ
- 譜面JSONと音源ファイルを読み込むローカルプレイ
- タイムライン式の創作譜面エディタ
- ローマ字入力による柔軟なタイピング判定
- スコア、コンボ、判定数、入力完了数、ミスタイプ数、最高KPSの表示
- Supabaseを利用した曲ごとのランキング表示・スコア送信

## 起動方法

### 必要な環境

- Node.js
- npm
- 音声を再生できるブラウザ

### 開発サーバー

PowerShellでプロジェクトのルートディレクトリを開き、次を実行します。

```powershell
npm install
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173/`）をブラウザで開いてください。
開発サーバーを停止するには、起動中のターミナルで `Ctrl+C` を押します。

### Supabaseの設定

ランキング機能を使うには、Supabaseプロジェクトを用意し、プロジェクトルートに `.env.local` を作成します。

```text
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

SupabaseのSQL Editorで [`supabase_setup.sql`](supabase_setup.sql) を実行すると、ランキング用の `rankings` テーブル、RLSポリシー、検索用インデックスが作成されます。

`.env.local` は公開リポジトリへコミットしないでください。設定を変更した場合は、開発サーバーを再起動してください。

### 本番ビルド

```powershell
npm run build
```

ビルド成果物は `dist/` に生成されます。

## 遊び方

### 公式譜面で遊ぶ

1. メニューで「公式譜面で遊ぶ」を選択します。
2. 曲選択画面で難易度や譜面制作者を絞り込み、難易度・長さ・ノーツ数で並び替えます。
3. 曲を選択するか、「あそぶ」を押してプレイを開始します。
4. ノーツが判定枠に重なったタイミングで、表示されている文字のローマ字を入力します。
5. プレイ終了後、結果画面でスコアや判定の内訳を確認します。

最初の1文字はリズム判定の対象です。続く文字は制限時間内に入力します。対応するローマ字は複数の入力方法を許容します（例: `し` は `shi`、`si`、`ci`）。

結果画面では、次のランクが表示されます。

- **全良**: すべて最高判定で、理論値と同じスコア
- **フルコンボ**: 入力抜けがなく完走（全良を除く）
- **クリア成功**: ミスがあっても理論値の70%以上
- **クリア失敗**: 理論値の70%未満

公式譜面のプレイ結果は、結果画面へ到達するとSupabaseへ送信されます。ローカル譜面の結果はランキングへ送信されません。曲選択画面または結果画面の「ランキング」から、スコア、最大コンボ、最高KPSを確認できます。

### 創作譜面を遊ぶ

1. メニューで「創作譜面を遊ぶ」を選択します。
2. 譜面JSONと音源ファイル（MP3、WAVなど）を読み込みます。
3. 両方のファイルを読み込んだら「スタート」を押します。

譜面JSONには `notes` 配列が必要です。各ノーツは、少なくとも `word`、`reading`、`time`、`endTime` を持つ形式で作成します。

```json
{
  "bpm": 120,
  "offset": 0,
  "notes": [
    {
      "id": "note-1",
      "word": "春",
      "reading": "はる",
      "time": 1000,
      "endTime": 1500,
      "type": "normal"
    }
  ]
}
```

### 創作譜面を作る

1. メニューで「創作譜面を作る」を選択します。
2. 必要に応じて音源を読み込み、BPMとOffsetを設定します。
3. タイムラインをクリックしてノーツを追加します。ノーツは16分音符単位にスナップされます。
4. ノーツを選択して、文字・読み・位置・長さを編集します。
5. `SAVE AS` または保存操作で譜面JSONを書き出します。
6. 保存したJSONと音源を「創作譜面を遊ぶ」から読み込んで確認します。

エディタでは、音源の波形表示、再生・一時停止、ルーラーからのシーク、ズーム、範囲選択、コピー・貼り付け、Undo/Redo、一括追加、一括置換、歌詞の一括流し込みに対応しています。

## エディタのショートカット

| ショートカット            | 操作                                 |
| ------------------------- | ------------------------------------ |
| `Space`                   | 再生 / 一時停止                      |
| `Delete` / `Backspace`    | 選択中のノーツを削除                 |
| `Ctrl+A`                  | すべて選択                           |
| `Ctrl+C` / `Ctrl+V`       | コピー / 貼り付け                    |
| `Ctrl+Z`                  | 元に戻す                             |
| `Ctrl+Y` / `Ctrl+Shift+Z` | やり直す                             |
| `Ctrl+S`                  | 上書き保存、未保存時は保存ダイアログ |
| `Ctrl+M`                  | 連続ノーツを一括追加                 |
| `Ctrl+H`                  | 選択中ノーツの一括置換               |
| `Ctrl+L`                  | 選択中ノーツへ歌詞を一括割り当て     |

## 公式譜面の追加

公式譜面は `public/songs/` 以下に配置し、`public/songs/index.json` に登録します。
1曲につき、譜面JSONと音源ファイルを同じ曲ディレクトリに置く構成です。

```text
public/
└─ songs/
   ├─ index.json
   └─ my-song/
      ├─ my-song.json
      └─ my-song.mp3
```

`index.json` には次のようなメタデータを追加します。

```json
{
  "id": "my-song",
  "title": "曲名",
  "creator": "譜面制作者",
  "difficulty": 5,
  "scorePath": "./songs/my-song/my-song.json",
  "audioPath": "./songs/my-song/my-song.mp3",
  "notesCount": 100,
  "durationMs": 60000
}
```

## npmスクリプト

| コマンド          | 内容                                                  |
| ----------------- | ----------------------------------------------------- |
| `npm run dev`     | Viteの開発サーバーを起動                              |
| `npm run build`   | 本番用ファイルを `dist/` に出力                       |
| `npm run publish` | ビルド後、変更をコミットして `origin/main` へプッシュ |

`npm run publish` はコミットメッセージの入力、Gitへのコミット、リモートへのプッシュを実行します。公開前に `git status` で変更内容を確認してください。
