# Typing Rhythm Game (仮称)

音楽ゲーム（リズムゲーム）のシビアなリズム判定と、タイピングゲームの爽快感を融合させた新感覚のブラウザゲームです。
専用の「ステップ入力式 譜面エディタ」を内蔵しており、好きな楽曲とテキストを組み合わせてオリジナルの譜面を作成・プレイすることができます。

## 🎮 ゲームの遊び方 (How to Play)

### 1. ゲームモードの選択
タイトル画面から、遊び方に合わせて以下のモードを選択します。

* **PLAY GAME**: 
  あらかじめプロジェクトに登録されている楽曲を「曲選択画面」から選んで、すぐにプレイを開始できます。
* **CUSTOM PLAY (LOCAL)**: 
  エディタで自作した専用の **譜面データ (score.json)** と **音声ファイル (.mp3 等)** をローカルから直接読み込んでテストプレイするモードです。
* **OPEN EDITOR**: 
  DAWライクな高機能タイムラインエディタを起動し、譜面を作成します。

### 2. ルールとタイピング仕様
ノーツ（単語）は音楽に合わせて右から左へスクロールします。左側の「判定ライン」に重なるタイミングでタイピングを行います。

* **柔軟なローマ字入力**:
  高度なローマ字パーサーを搭載しており、プレイヤーの入力の癖に柔軟に対応します。
  （例: 「し」= `shi` / `si` / `ci`、「ん」= `nn` / 次の子音によっては単独の `n`、「っ」= 子音の重ね入力 等を動的に判定）
* **1打目のシビアな判定**: 
  単語の「最初の1文字目」のみ、リズムゲームとしてのシビアな時間判定が行われます。タイミングを合わせて正確にキーを叩いてください。
* **2打目以降の早打ち**: 
  2文字目以降はリズム判定はありません。単語ごとの有効期限（タイムリミット）までに、残りの文字を素早く打ち切ってください（ホールド/連打扱い）。
* **強制ミスとターゲット移行**:
  現在の単語のタイムリミットを過ぎた場合、または次の単語が直後に迫っている場合は、未完了であっても強制的に「ミス（DROPPED）」として打ち切られ、ターゲットは自動的に次の単語へ移行します。

### 3. クリアランク
ゲーム終了時、スコアとミス数に応じて以下のクリアランクがリザルト画面に表示されます。

* **ALL JUSTICE**: 獲得スコアが理論値（全て最高判定）と完全に一致
* **FULL COMBO**: ミス（DROPPED）が0回で完走（ALL JUSTICEを除く）
* **CLEAR**: 獲得スコアが理論値の70%以上
* **FAILED**: 獲得スコアが理論値の70%未満

## 🛠️ 譜面エディタの使い方 (Editor Mode)

タイトル画面から「OPEN EDITOR」を選択すると、タイムラインエディタが起動します。

### 基本操作
* **ノーツの配置**: 16分音符のグリッドに沿って、タイムライン上をクリックするとノーツ（四角形）が配置されます（自動スナップ機能搭載）。
* **長さの調整**: ノーツの「右端」をドラッグすると長さを変更できます。
* **時間の移動**: ノーツの「中央」をドラッグすると、配置する時間を移動できます。
* **テキストの入力**: ノーツをダブルクリック（またはEnter）で最前面にポップアップが開き、単語とひらがな（読み）を設定できます。
* **削除とUndo/Redo**: 選択して `Delete` / `Backspace` で削除。`Ctrl + Z` で元に戻す、`Ctrl + Shift + Z` でやり直しが可能です。

### 音楽の同期とプレビュー
* ヘッダーから音源を読み込むと波形（Waveform）が自動抽出され、背景に描画されます。
* `Space` キーで無音、または音源付きのプレビュー再生/一時停止ができます。
* **ルーラー領域のシーク**: タイムライン上部の目盛り領域（ルーラー）をクリック・ドラッグすることで、好きな再生位置へ瞬時にプレビューを飛ばせます。
* **BPM / Offset調整**: 楽曲のBPM（テンポ）とOffset（開始位置のズレ）を微調整し、グリッドと波形を完璧に同期させることができます。

### KPS警告システム
物理的にタイピングが不可能な譜面を防ぐため、1秒間あたりの要求打鍵数（KPS: Keys Per Second）をリアルタイムに計算しています。KPSが `10` を超えるノーツは枠線が赤く警告表示されます。

### 譜面の Export / Import
作成した譜面は「Export」ボタンから `score.json` としてダウンロードできます。「Import」から読み込むことで、いつでも作業を再開できます。

## 📂 新しい曲の追加方法 (For Admins)

プロジェクト内に新しい曲をプリセットとして追加する場合、以下の運用フローに従います。
（AIエージェントにJSONとMP3を渡し、「この曲を追加して」と指示することでも実行可能です）

1. **ファイルの配置**:
   `public/songs/` の中に、任意の曲ID（例: `my-song`）でディレクトリを作成し、譜面データ（`.json`）と音源（`.mp3`）を格納します。
2. **マスターリストの更新**:
   `public/songs/index.json` の配列に、新しい曲のメタデータを追記します。
   ```json
   {
     "id": "my-song",
     "title": "曲のタイトル",
     "creator": "譜面作者名",
     "scorePath": "./songs/my-song/score.json",
     "audioPath": "./songs/my-song/audio.mp3"
   }
   ```
3. ゲームを起動し、「PLAY GAME」のリストに追加されていれば完了です。

## 💻 開発環境のセットアップ (For Developers)

このプロジェクトは React, Vite, Zustand, そして Vanilla JS を組み合わせて構築されています。

```bash
# パッケージのインストール
npm install

# ローカル開発サーバーの起動
npm run dev
```
